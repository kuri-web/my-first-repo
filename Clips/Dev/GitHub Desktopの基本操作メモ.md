# GitHub Desktopの基本操作メモ

## よく使う操作

- **Changes タブ**: 前回のコミットから変わったファイルを一覧で確認する
- **Commit to main**: 変更に名前（Summary）を付けて記録する
- **Push origin**: 記録した変更を GitHub（インターネット上）に送る
- **Fetch / Pull origin**: GitHub 側の最新の状態を取り込む
- **History タブ**: これまでのコミットの履歴を見る

## 困ったとき

- 変更を取り消したい → ファイルを右クリックして「Discard changes」
- 直前のコミットを取り消したい → History で右クリックして「Undo commit」（Push する前だけ）
